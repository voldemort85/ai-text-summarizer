\# AI Text Summarizer



An AI-powered text summarization application built using Hugging Face Transformers and Gradio.



\## Overview



This project generates concise summaries from long pieces of text using a pre-trained Transformer model. It provides a simple and interactive web interface built with Gradio.



\## Features



\* Summarizes lengthy text into shorter versions

\* User-friendly Gradio interface

\* Powered by Hugging Face Transformers

\* Fast and efficient text processing



\## Technologies Used



\* Python

\* Hugging Face Transformers

\* PyTorch

\* Gradio



\## Project Structure



```text

Text\_Summary.py      # Main application file

README.md            # Project documentation

requirements.txt     # Project dependencies

```



\## Installation



1\. Clone the repository:



```bash

git clone https://github.com/voldemort85/ai-text-summarizer.git

```



2\. Navigate to the project directory:



```bash

cd ai-text-summarizer

```



3\. Install dependencies:



```bash

pip install -r requirements.txt

```



\## Running the Application



```bash

python Text\_Summary.py

```
